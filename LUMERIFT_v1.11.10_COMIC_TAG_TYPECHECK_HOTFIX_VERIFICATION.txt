LUMERIFT v1.11.10 Comic Tag Typecheck Hotfix
Date: 2026-07-29

Root cause:
- createComicTag(text, color = COLORS.primaryBright) inferred color as the literal type 0xa1fff2.
- Passing COLORS.primary, COLORS.sunrise, or 0xf0ca78 therefore failed with TS2345.

Fix:
- Explicitly typed the parameter as number:
  createComicTag(text: string, color: number = COLORS.primaryBright)
