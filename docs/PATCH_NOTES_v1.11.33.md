# LUMERIFT v1.11.33 Patch Notes

## 핵심 업데이트

- 플레이어 얼굴·헤어·갑주·망토의 8방향 피벗과 가림 순서를 v17 래스터 파츠로 분리했습니다.
- 검·대검·균열 장창의 공격 프레임별 위치·회전·크기 보정을 무기 계열별로 분리했습니다.
- Void·Frost·Inferno 엘리트와 Abyssal 보스에 머리·몸통·앞다리·뒷다리·등·꼬리 전신 확장 파츠를 적용했습니다.
- 보스 코어 FX를 12프레임에서 24프레임으로 확장하고 안정 상태를 보호 상태 아트로 안전하게 정규화했습니다.
- Premium UI Icons를 24개로 확장해 전투·인벤토리·캐릭터 스튜디오·복구·Cloud·모바일 승인 화면에 연결했습니다.

## 안전 계약

- Player Save v4, AttackFootprint, 전투 수치와 Firebase App Check 비활성 정책은 변경하지 않았습니다.
- v17 로딩 실패 시 v16 래스터 파츠, v10/v11 본체, v4 몬스터와 프로그램형 레이어로 폴백합니다.
- 이번 배치는 방향별 합성 파츠와 전신 범위 확장 단계이며 최종 8방향 전신 수작업 Atlas 완성을 의미하지 않습니다.
