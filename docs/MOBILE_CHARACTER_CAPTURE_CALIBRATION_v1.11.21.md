# Mobile Character Capture Calibration v1.11.21

## 현재 상태

이 릴리스에는 Android Chrome·iOS Safari 물리 기기 캡처가 포함되지 않았다. 아래 값은 캡처 세션을 시작하기 위한 보수적 기준이며 최종 승인값이 아니다.

| 플랫폼 | 기준 화면 | 스튜디오 크기 | 전투 크기 | 발광 | 오버레이 |
|---|---:|---:|---:|---:|---:|
| Android Chrome | 412×915 CSS px / DPR 2.625 | 96% | 98% | 90% | 92% |
| iOS Safari | 390×844 CSS px / DPR 3 | 93% | 96% | 82% | 86% |
| 모바일 공통 | 9:16 | 95% | 97% | 88% | 90% |
| Desktop | 540×960 디자인 캔버스 | 100% | 100% | 100% | 100% |

모든 프로필의 `captureStatus`는 `pending-physical-capture`다.

## 실제 캡처 승인 절차

1. Android Chrome과 iOS Safari에서 캐릭터 스튜디오 8방향·3개 무기 계열·3개 코스튬을 각각 캡처한다.
2. 전투 60초 이상을 실행해 대기·이동·3연격·스킬·회피 크기와 발광 번짐을 확인한다.
3. 화면 가장자리 잘림, 발 피벗, 무기 실루엣, 룬 발광, HUD 겹침을 기록한다.
4. 측정 근거와 캡처 파일이 확보된 플랫폼만 `capture-verified`로 전환한다.
