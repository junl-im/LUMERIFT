# LUMERIFT v1.11.19 Patch Notes

## Added

- 기본 전투용 프리미엄 8방향 플레이어 본체 Atlas v10
- 4종 캐릭터 염색 프리셋과 로컬 저장
- 균열검·대검·균열 장창 무기 실루엣
- 장비 3부위 세트 조화 표시
- v1.11.19 누적 회귀 검증기

## Changed

- 기본 플레이어 런타임 경로를 v4에서 v10으로 전환
- 로비 장비 미리보기에 무기 계열·염색·세트 조화 추가
- 설정의 캐릭터 원화 버튼을 본체·염색 두 버튼으로 분리
- 새 본체 크기에 맞춰 기본 전투 스케일을 조정

## Preserved

- Firebase App Check 비활성
- Player Save v4
- `AttackFootprint` 공유 판정
- 화면 기준 조이스틱 이동
- v4 레거시 fallback과 v6/v7 선택형 원화

## Known limitations

- 신규 본체는 기존 라이선스 자산을 기반으로 제작한 production-candidate 파생 Atlas다.
- Android Chrome·iOS Safari 물리 기기에서 크기와 발광 강도를 아직 최종 승인하지 않았다.
