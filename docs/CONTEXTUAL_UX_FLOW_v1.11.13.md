# Contextual UX Flow v1.11.13

## 로비 NEXT BEST ACTION

우선순위는 수령 가능한 퀘스트 보상 → 운영 알림 → 미완료 스토리 → 에셋 품질 점검 순서다.
추천 카드와 주 행동 버튼은 같은 `LobbyNextAction` 결과를 사용하므로 문구와 실제 이동 목적지가 어긋나지 않는다.

## 설정 피드백

설정 변경 후 재진입할 때 작은 인라인 배너로 적용 결과를 표시한다. 메시지가 없을 때는 즉시 저장과 조이스틱 화면 기준 기본값을 안내한다.

## 결과 행동 계획

승패, 클리어 시간, 콤보, 다음 스테이지, 아이템 드롭을 `ResultActionPlan`에서 판단한다. 성과 배지·추천 문구·주 버튼이 같은 결과를 공유한다.
