## 배포 원칙

고해상도 원본은 웹게임 실행과 GitHub Pages 배포에 필요하지 않으므로 기본 전체 ZIP에 포함하지 않는다. 원본 재가공이 필요한 경우 라이선스 문서에 기록된 원출처에서 다시 확보하거나 별도 소스 보관본을 사용한다.
