# LUMERIFT v1.11.1 패치 노트

## 추가

- 3단계 기기 보정 프로필과 전투 렌더 편향값
- 기존 8방향 Atlas 기반 플레이어 모션 디렉터
- 보스 위험 장판 예고·위험·회피 언어
- impact tier별 프로그램 VFX 악센트
- 단일 포인터 전투 입력 게이트
- 8방향 4동작 제작용 모션 블록아웃 원본

## 변경

- AdaptivePerformanceController의 저하·회복 임계값을 기기 프로필로 분리
- CombatRenderBudget이 기기 편향값을 함께 반영
- Device QA JSON과 설정 화면에 보정 등급 표시

## 유지

- 신규 런타임 이미지 없음
- Player Save v4, Firebase, 랭킹, AttackFootprint 유지
- App Check 비활성화 유지

## 미검증

- 물리 Android·iOS 장시간 온도·배터리·GPU 메모리
- 제작용 블록아웃의 최종 런타임 아트 승인
