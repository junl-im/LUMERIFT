# 실기기 QA 세션 v1.11.2

## 수집 항목

QA 기록을 시작하면 3초 간격으로 다음 항목을 누적한다.

- FPS와 1% Low
- 33ms·50ms 초과 프레임 비율
- P99 프레임 시간
- 자동 품질 단계와 추정 부하 상태
- 캔버스 해상도, 그래픽 적용 모드, 목표 FPS
- visualViewport 크기와 Safe Area 관련 오프셋
- 화면 표시 상태와 방향 전환 횟수
- 지원 브라우저의 Battery Status API 시작·종료 잔량

## 물리 측정 제한

브라우저에서 신뢰할 수 없는 표면 온도와 GPU 메모리는 `null`로 기록한다. 별도 온도계·OS 도구로 측정한 값만 외부 QA 기록에 추가한다.

## 권장 절차

1. 설정에서 QA 기록 시작
2. 동일 스테이지를 20분 이상 반복 플레이
3. 설정으로 돌아와 QA 기록 종료
4. QA JSON 저장
5. 기기명, OS, 브라우저 버전, 표면 온도, 배터리 감소율을 별도 시트와 함께 보관
