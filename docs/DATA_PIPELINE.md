# JSON Data Pipeline

## 목적

콘텐츠를 추가할 때 핵심 Controller 코드를 수정하지 않고 JSON 데이터만 추가할 수 있도록 한다.

## 데이터 파일

### actions.json

기본 공격과 스킬의 시간, 범위, 피해 계수, 이펙트 색상, 상태 이상을 정의한다.

### player.json

플레이어 기본 능력치와 콤보·스킬 액션 ID를 연결한다.

### monsters.json

몬스터의 전투 수치, 표시 색상, 등급, 공격 패턴을 정의한다.

### items.json

장비 부위, 등급, 기본 능력치, 판매가, 강화 비용과 최대 단계를 정의한다.

### stages.json

플레이어 시작 위치, 웨이브, 스폰 좌표, 클리어 보상과 장비 드롭 테이블을 정의한다.

## 검증 단계

1. JSON 문법 검사
2. 필수 필드와 수치 범위 검사
3. 색상 `#RRGGBB` 검사
4. 중복 ID 검사
5. 플레이어 → 액션 참조 검사
6. 스테이지 → 몬스터 참조 검사
7. 스테이지 → 아이템 참조 검사
8. 장비 부위·등급 검사
9. 드롭 확률 0~1 검사
10. 보스 패턴 3개 이상 검사

검증에 실패하면 게임을 정상 시작시키지 않고 정확한 데이터 경로가 포함된 오류를 발생시킨다.

## 추가 규칙

- ID는 출시 후 가능한 한 변경하지 않는다.
- 표시 이름 변경과 ID 변경을 구분한다.
- 전투 수치는 JSON에만 둔다.
- Pixi 표시 클래스는 피해량과 쿨다운을 결정하지 않는다.
- 데이터 버전이 증가하면 마이그레이션 문서를 추가한다.
- 스테이지 좌표는 540 × 960 논리 해상도를 기준으로 한다.

## Quest and Stage Data v0.5

- `stages.json`은 버전 2이며 순서, 유형, 설명, 이전 스테이지, 최초 보상을 포함한다.
- `quests.json`은 메인·일일 퀘스트, 선행 퀘스트, 조건, 보상을 정의한다.
- 검증기는 몬스터·아이템·스테이지·퀘스트 상호 참조와 MVP 수량을 검사한다.
