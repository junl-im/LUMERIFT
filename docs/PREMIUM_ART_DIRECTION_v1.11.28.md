# LUMERIFT Premium Art Direction v2 · v1.11.28

## 확정 기준

v1.11.28부터 승인된 캐릭터·몬스터 쇼케이스 2종을 LUMERIFT 차기 전체 아트 제작 기준선으로 사용한다.

- 캐릭터: 얼굴, 갑주, 망토, 룬, 무기 변형, 전투 포즈와 8방향 실루엣을 한 세트로 설계한다.
- 몬스터: 종족 실루엣, 머리와 발톱, 재질, 속성 변형, 공격 포즈와 방향별 형태를 한 세트로 설계한다.
- UI: 미드나이트 네이비 기반의 금속·유리 프레임, 실버·소프트 골드 계층, 블루·바이올렛 발광을 사용한다.
- 스킬 VFX: 룬 문법, 중심 타격, 잔상 감쇠, 속성별 색상과 렌더 예산 단계를 유지한다.
- 무기·장비: 금속·천·크리스털 재질을 명확히 분리하고 작은 모바일 화면에서도 계열과 등급이 읽혀야 한다.

## 품질 게이트

`PremiumArtDirection.ts`는 캐릭터·몬스터·UI·스킬 VFX·장비의 가중 품질 기준을 제공한다.

- 캐릭터 목표: 92점
- 몬스터 목표: 91점
- UI 목표: 90점
- 스킬 VFX 목표: 90점
- 장비 목표: 91점
- 모든 도메인은 모바일 판독성 80점 미만이면 총점과 무관하게 탈락한다.

## 파일 정책

- 제작용 마스터: `art_source/lumerift_original/v1.11.28/art-direction`
- 런타임 감수용: `public/assets/live/v12/art-direction`
- 감수용 이미지는 WebP이며 941×1672로 보존한다.
- 감수용 번들은 Lazy Reference 전용이며 `core-ui`와 전투 시작 번들에 포함하지 않는다.
- 런타임 전투 캐릭터·몬스터 Atlas가 이 쇼케이스와 동일해졌다고 주장하지 않는다. 이번 버전은 제작 기준선과 검수 파이프라인을 확정한 단계다.

## 확장 순서

1. 플레이어 캐릭터 본체와 장비 파츠
2. 엘리트 몬스터와 보스
3. 스킬·피격·보스 패턴 VFX
4. 공통 UI·아이콘·프레임
5. 지역 배경·NPC·키아트

각 단계는 Texture Atlas, Lazy Loading, 15MB 초기 다운로드 예산, 9:16 모바일 판독성을 통과해야 한다.
