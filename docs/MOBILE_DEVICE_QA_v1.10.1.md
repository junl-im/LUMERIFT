# 모바일 실기기 QA 계측 v1.10.1

## 목적

브라우저가 직접 제공하지 않는 발열 센서값을 임의로 주장하지 않고, 실제 단말에서 관찰 가능한 프레임 시간·뷰포트·렌더 설정을 JSON으로 수집한다.

## 수집 항목

- 평균 FPS와 1% Low
- 33.34ms 초과 긴 프레임 비율
- 50ms 초과 심각 프레임 비율
- 최대 프레임 시간과 최근 프레임 추세
- 기기 메모리 API 값, 논리 코어 수, DPR, 터치 포인트
- visualViewport 너비·높이·오프셋·배율과 키보드 오프셋
- 캔버스 resolution, 자동 품질 단계, 그래픽 선호·실제 적용 단계
- 접근성 모드

## 사용 절차

1. Android Chrome·Samsung Internet 또는 iOS Safari에서 게임을 연다.
2. 설정 화면에서 FPS를 `AUTO`로 유지한다.
3. 전투를 포함해 최소 1분 이상 플레이한다.
4. 설정 → `기기 QA JSON 저장`을 누른다.
5. 동일 기기에서 화면 회전·주소창 접힘·가상 키보드 입력을 각각 한 번 수행한 뒤 다시 저장한다.

## 자동 단계

- `full`: 원래 resolution과 최대 그래픽 선호를 유지한다.
- `balanced`: 그래픽을 균형 단계 이하로 제한하고 resolution을 기본값의 86%로 조정한다.
- `safe`: 그래픽을 절전 단계로 제한하고 AUTO FPS를 30으로 낮추며 resolution을 기본값의 72%로 조정한다.

단계 하향은 1% Low와 긴 프레임이 여러 측정 구간에서 연속 저하될 때만 수행한다. 상향은 60~90초 이상 안정 상태가 유지돼야 한다.

## 주의

`estimatedPressure`는 실제 배터리 온도나 SoC 온도 센서값이 아니다. 지속적인 프레임 악화에서 추정한 성능 압력 지표다. 실제 발열 승인은 기기 표면 온도 또는 제조사 진단 도구와 함께 수동 기록해야 한다.
