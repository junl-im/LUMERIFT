# LUMERIFT v1.7.0 실사용 아트 통일 1차

## 목적

v1.2~v1.6의 실사용 공개 원본은 런타임 연결과 라이선스 측면에서는 유효했지만, 모바일 화면에서 캐릭터와 배경의 명암 분리와 지역별 전투 분위기가 부족했다. v1.7.0은 기존 프레임 키를 유지하면서 실제 전투 판독성을 높이는 통일 패스다.

## 품질 단계

`production-candidate-unified-art-pass`

- 실제 런타임 기본 경로에 연결된다.
- 플레이어·몬스터·VFX·전투 배경·보스 초상을 동일한 Teal·Gold·Corruption 팔레트로 보정했다.
- 공개 라이선스 원본 기반 파생물이므로 LUMERIFT 독점 최종 원화 또는 `final-approved`로 보고하지 않는다.

## 런타임 자산

- 플레이어 Atlas: 68프레임, 80애니메이션 키
- 몬스터 Atlas: 8종, 268프레임, 66애니메이션 키
- VFX Atlas: 5종, 40프레임
- Chapter 1 전투 배경: 접근·폐허·심층·균열핵 4단계
- 보스 초상: 1·2·3페이즈 3종
- 로비 배경과 영웅 초상 v4

## 시각 규칙

- 플레이어: 청록 림라이트와 금속 금색 포인트
- 일반 몬스터: 종별 색상 구분을 유지하되 공통 암부와 외곽선을 적용
- 정예: 금색·청록 대비 강화
- 보스: 적색 → 자색 → 진홍색으로 페이즈 위험도 상승
- 전투 배경: 캐릭터 이동 영역을 어둡게 단순화하고 균열 원형 룬으로 전투 중심을 표시
- VFX: 공격·피격·폭발·회피가 서로 다른 색과 실루엣으로 구분되도록 8프레임화

## 스테이지 매핑

- 1~2: `approach`
- 3~5: `ruins`
- 6~8: `depths`
- 9~10: `core`

`StageVisualProfile.ts`가 배경, 전투 링 색, 장식 시드와 오염도를 한 번에 결정한다.

## 보존 정책

v2 플레이어·몬스터·배경·초상과 기존 VFX는 삭제하지 않고 `art_source/runtime_archive/v1.7.0/public/assets`로 이동했다. 이동 전후 SHA-256은 `asset_registry/RELOCATION_PLAN_v1.7.0.json`에 기록한다.

## 남은 한계

- 플레이어와 몬스터 실루엣 자체는 공개 원본 기반이다.
- 방향별 완전 독립 원화가 아니라 기존 프레임 계약을 유지한 통일 보정이다.
- Android Chrome과 iOS Safari에서 실제 크기·명암·GPU 업로드 시간을 확인해야 한다.
