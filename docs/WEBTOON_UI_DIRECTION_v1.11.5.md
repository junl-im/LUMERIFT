# v1.11.5 웹툰형 UI 디자인 방향

## 목표
- 기존 glass 기반 UI를 유지하되 더 덜 밋밋하고, 모바일 화면에서 또렷한 웹툰형 인상을 준다.
- 복잡한 신규 이미지 없이도 패널·버튼·광택·배지·스티커형 포인트로 인상 차이를 만든다.

## 적용
- `UiSkin`: 패널 그림자, 코너 스티커, 상단 하이라이트를 추가해 카드 느낌 강화
- `UiButton`: 버튼 내부 광택과 상단 포인트 라인을 추가해 평면감 완화
- `CombatActionButton`: ACTION / SKILL / DODGE 배지와 flare를 추가해 역할이 즉시 보이도록 정리
- `VirtualJoystick`: 8방향 가이드와 heading needle을 추가해 방향성이 더 명확하게 보이도록 구성

## 미완료
- 실사용 전용 일러스트 교체
- 씬별 전용 웹툰 말풍선 아트셋
- 실브라우저 터치 스크린샷 기반 최종 미세 조정
