# v1.11.11 캐릭터 이동 방향 핫픽스

## 확인된 원인
가상 조이스틱은 화면 기준 좌표를 정상 출력하고 있었지만, `JoystickCalibrationController`의 초기값이 `reverse`로 설정되어 있었습니다.
이 때문에 조이스틱 입력이 전투 직전에 X·Y축 모두 반전되어 캐릭터 위치, 바라보는 방향, 8방향 애니메이션이 손가락 입력과 정반대로 적용됐습니다.

## 수정
- 기본 모드를 `screen`으로 변경
- 저장 키를 `joystickCalibration.v2`로 올려 과거 자동 저장된 반전 기본값을 초기화
- 좌우·상하·전체 반전은 사용자가 명시적으로 설정한 경우에만 적용
- 설정 화면에 화면 기준이 정상 기본값임을 표시
- 기본/좌우/상하/전체 반전 단위 테스트 추가

## 영향 범위
- 가상 조이스틱 이동만 기본 방향을 수정
- 키보드 이동, 화면 터치 이동, 자동 전투 이동 벡터는 변경하지 않음
- 8방향 애니메이션 선택은 수정된 실제 이동 방향을 그대로 사용
