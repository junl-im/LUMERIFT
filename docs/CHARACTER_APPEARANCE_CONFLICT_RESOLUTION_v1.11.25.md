# Character Appearance Conflict Resolution v1.11.25

## 선택 가능한 병합 범위

1. 외형 슬롯 1
2. 외형 슬롯 2
3. 외형 슬롯 3
4. 슬롯 표시 순서
5. 슬롯 고정 상태
6. 최근 외형 프리셋

슬롯은 `local`, `remote`, `newer` 중 하나를 선택한다. `newer`는 슬롯의 `savedAt`을 비교하되 로컬 고정 슬롯은 항상 로컬 값을 유지한다. 슬롯 고정 상태는 로컬, Cloud, 합집합 중 하나를 선택할 수 있으며 기본값은 합집합이다.

최근 프리셋 기본값은 선택 병합이다. 동일 외형 서명은 한 항목으로 합치고, 즐겨찾기는 OR 방식으로 보존하며, 표시 이름은 의미 있는 이름 중 가장 최근 값을 선택한다. 결과는 최대 5개로 제한한다.

## 안전 적용 순서

1. 현재 로컬 Archive를 `pre-conflict-merge` 복구 지점으로 저장한다.
2. 선택한 병합 계획으로 Archive v3 통합본을 만든다.
3. 로컬 외형 Archive를 통합본으로 교체한다.
4. 사용자 동의가 유지된 경우 통합본을 Cloud에 업로드한다.
5. 성공 시 충돌 후보와 재시도 상태를 정리한다.

자동으로 전투 능력치, 장비 UID, 인벤토리, Player Save v4를 변경하지 않는다.
