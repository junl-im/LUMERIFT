# LUMERIFT v1.2.0 UI·그래픽 전면 점검

## 결론

v1.0~v1.1 화면은 기능은 동작하지만 시각적으로 다음 문제가 있었다.

- 로비와 메뉴가 게임 화면보다 업무용 대시보드처럼 보였다.
- 패널 수가 지나치게 많고 화면의 중심이 분산됐다.
- 캐릭터·몬스터·배경·UI가 서로 다른 출처와 명암 체계를 사용했다.
- 전투 HUD가 넓고 두꺼워 실제 전투 영역을 가렸다.
- 인벤토리가 아이템 그리드가 아니라 텍스트 목록에 가까웠다.
- 스테이지 선택 화면이 동일한 사각 버튼의 반복이었다.
- 결과 화면에서 전투 등급과 보상보다 패널 자체가 더 눈에 띄었다.

## v1.2.0에서 수정한 내용

### 공통 디자인 시스템

- 흑청색 Obsidian 바탕, 금색 주요 보상, 청록색 상호작용으로 색 역할을 고정했다.
- 반복적인 네온 테두리와 두꺼운 패널을 줄였다.
- 모든 주요 패널과 버튼을 동일한 34px NineSlice 규격으로 통일했다.
- 작은 설명 텍스트와 핵심 행동 버튼의 명도 차이를 확대했다.

### 로비

- 거대한 정보 패널을 줄이고 캐릭터·오늘의 작전·주 행동 순서로 재배치했다.
- 하단 메뉴를 네 개의 동일한 탐색 영역으로 통일했다.

### 전투

- 플레이어 HP·웨이브·보스 HP를 상단에 압축했다.
- 조이스틱과 스킬 버튼의 시각 계층을 정리했다.
- 새 HUD 좌표와 실제 HP 게이지 갱신 좌표를 일치시켰다.

### 인벤토리

- 5개 텍스트 목록을 3×4 아이템 그리드로 교체했다.
- 등급, 장착, 잠금, 강화 수치를 슬롯에서 즉시 식별할 수 있게 했다.
- 상세 패널에서 전투력, 능력치, 강화 비용, 네 개 행동을 한 영역에 묶었다.

### 스테이지

- 동일 버튼 반복을 작전 경로와 일반·정예·보스 노드로 교체했다.
- 잠금, 선택, 클리어 횟수, 권장 전투력을 별도의 시각 상태로 표시했다.

### 결과

- 등급 메달을 화면 중심으로 이동했다.
- 처치·콤보·시간을 같은 규격의 통계 카드로 정리했다.
- 보상과 다음 행동을 명확히 분리했다.

### 그래픽

- 플레이어와 몬스터 Atlas에 동일한 대비·윤곽·색온도 보정 패스를 적용했다.
- 로비·전투 배경과 초상은 같은 명암 방향으로 재가공했다.
- 기본 AssetCatalog를 v2 아트 경로로 전환했다.

## 남은 품질 한계

v1.2.0은 UI 구조와 색·명암 통일을 크게 개선한 버전이지만 `final-approved`가 아니다.

- 플레이어와 몬스터 원화는 LUMERIFT 전용 독점 제작물이 아니다.
- 공개 원본 간 형태 언어와 세부 묘사 수준은 완전히 일치하지 않는다.
- 전용 8방향 캐릭터·몬스터 원화가 없으므로 아트 교체가 계속 필요하다.
- 실기기에서 폰트 크기, Safe Area, 저사양 GPU 메모리 검수가 남았다.

현재 품질 단계는 `production-candidate-open-art-pass`를 유지한다.
