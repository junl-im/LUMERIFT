# LUMERIFT v0.9.0 패치 노트

## 에셋 품질 개선

- v0.8 구조 검증팩의 한계를 공식 기록
- 고해상도 PNG 원본과 런타임 WebP를 분리
- 신규 품질 Atlas 26개·1,300프레임
- 영웅·보스·NPC 초상, 아이템·스킬, 환경, VFX, UI 대규모 확장
- 지역 키아트와 전투 배경 품질 개선
- 카테고리별 Lazy Loading 품질 보관소

## 규칙 강화

- 품질 단계 5단계 정의
- 절차형 후보를 최종급으로 표현하는 보고 금지
- 런타임·원본 용량과 수량을 릴리스 필수 보고 항목으로 지정
- `validate:art` 자동 품질·진실성 검사 추가

## 제한

현재 자산은 최종 상용 원화가 아니라 `production-candidate-procedural` 단계다.
