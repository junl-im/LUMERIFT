# LUMERIFT v1.11.0 전투·그래픽 강화 설계

## 목표

기존 AttackFootprint 판정과 모바일 성능 계약을 유지하면서 공격의 입력 연결성, 스킬 선택의 의미, 적중 피드백, HUD 가독성과 저사양 자동 축소를 하나의 전투 프레젠테이션 계층으로 통합한다.

## 전투 시스템

- Rift Drive 최대값은 100이다.
- 적중·치명타·처치·정밀 회피가 Drive와 스타일 체인을 증가시킨다.
- 스타일 등급은 D, C, B, A, S, SS 6단계다.
- Drive 100 도달 시 7초 Overdrive가 발동한다.
- 공격 적중 뒤 스킬 또는 회피로 캔슬할 수 있다.
- 정밀 회피는 Drive를 제공하고 스킬·회피 쿨다운을 줄인다.

## 행동 데이터

모든 공격·스킬 행동은 `impactTier`, `driveGain`, `driveCost`, `comboWindow`를 가진다. 텔레그래프와 실제 공격 판정은 계속 같은 AttackFootprint를 사용한다.

## 적응형 렌더 예산

`CombatRenderBudget`은 그래픽 설정과 실시간 성능 압력을 바탕으로 다음을 제한한다.

- 동시 전투 이펙트 수
- 곡선과 호의 세그먼트 수
- 타격광 레이어 수
- 동시 데미지 텍스트 수
- 배경 전술 격자와 주변 광량 강도

FULL은 다층 광원과 정밀 곡선을 유지하고, BALANCED와 SAFE는 게임 판정에 영향을 주지 않은 채 시각 비용만 줄인다.

## UI·그래픽

- Drive 게이지와 D~SS 스타일 등급
- 스킬 Drive 충전 링과 강화 준비 펄스
- 공통 패널 상단 하이라이트, 하단 그림자, 코너 악센트
- 진행 바 외곽선과 구간 눈금
- 로비·설정의 FPS·적응형 품질·렌더 예산 진단

신규 런타임 이미지는 추가하지 않는다. 기존 WebP Atlas와 PixiJS Graphics를 사용하므로 초기 다운로드 용량은 증가하지 않는다.

## 성능·품질 진실성

정적 검사와 컴파일 검사는 수행하지만 실제 Android·iOS의 온도, 배터리, GPU 메모리와 장시간 FPS는 물리 단말에서 측정해야 한다. 프로그램 렌더링 강화는 최종 독점 원화 업그레이드와 구분한다.
