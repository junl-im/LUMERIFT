# LUMERIFT v1.11.35 Patch Notes

## 핵심 업데이트

- 플레이어 공격·회피·스킬을 접촉·유지·회수 3단계로 분리한 8방향 래스터 오버레이 72프레임을 추가했다.
- Void·Frost·Inferno·Abyssal 계열 몬스터에 정면·측면·후면·3/4 방향 사지 오버레이 48프레임을 연결했다.
- 보스 코어 보호·균열·파괴·재생·폭주에 연속 파편 궤적 36프레임을 적용했다.
- slash·hit·nova·explosion·dodge·ultimate 프리미엄 전투 VFX 24프레임을 기존 v4 효과 위에 합성한다.
- v19 로딩 실패 시 v18·v17·v16 및 기존 프로그램형 효과로 안전하게 폴백한다.

## 보존 계약

Player Save v4, AttackFootprint 단일 판정, Firebase App Check 비활성 정책은 변경하지 않았다. v19은 고품질 래스터 합성 단계이며 최종 8방향 전신 수작업 Atlas 완성으로 기록하지 않는다. Android Chrome·iOS Safari 물리 기기 승인과 실제 npm 의존성 기반 빌드는 미완료 상태다.
