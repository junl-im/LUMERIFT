# LUMERIFT v1.10.0 시각 감사

## 발견된 문제

1. `visualViewport.height`를 루트 높이로 적용한 뒤 키보드 오프셋을 다시 차감해 입력 화면이 과도하게 줄어들 수 있었다.
2. 36~42 높이의 작은 운영·퀘스트 버튼은 축소된 모바일 캔버스에서 44 CSS px에 미달할 수 있었다.
3. 스테이지·퀘스트 상태가 텍스트 중심이라 빠른 판독성이 낮았다.
4. 결과 화면의 보상과 다음 행동이 동일한 사각 버튼 반복으로 보였다.
5. 쿠폰 입력이 `window.prompt`에 의존해 Safe Area·키보드·디자인 시스템 통제가 불가능했다.

## 수정 결과

- 게임 호스트의 키보드 높이 중복 차감을 제거했다.
- 공통 터치 판정을 최소 48 논리 픽셀로 확대했다.
- 상태·보상·행동 아이콘을 기존 `ui_icons_v5`에서 재사용해 신규 런타임 이미지 용량을 추가하지 않았다.
- 선택·보상 준비·메달에 저강도 마이크로 인터랙션을 추가했다.
- 쿠폰 전용 DOM 오버레이와 입력 검증을 추가했다.

## 품질 판정

- UI 구조: production-candidate-unified-art-pass 유지
- 전용 독점 원화: 아님
- 신규 런타임 이미지: 없음
- 초기 다운로드 영향: 사실상 없음
- 실제 물리 기기 최종 승인: 미완료, v1.10.1 수동 계측 예정
