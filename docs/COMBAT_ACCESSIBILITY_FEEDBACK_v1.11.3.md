# 전투 접근성 피드백 v1.11.3

## 진동

지원 브라우저에서 UI, 공격, 치명타, 스킬, 회피, 정밀 회피, 피격, 보스 예고, 즉시 회피, Overdrive를 서로 다른 짧은 패턴으로 구분한다. 반복 공격·피격은 최소 간격으로 제한해 과도한 진동을 방지한다.

## 화면 낭독

화면 밖 ARIA Live Region을 사용해 다음 핵심 사건만 읽는다.

- 보스 공격 예고
- 즉시 회피 단계
- 정밀 회피 성공
- 체력 25% 이하
- Rift Drive Overdrive 발동

동일 문구는 일정 시간 중복 낭독하지 않는다. 설정에서 진동과 전투 낭독을 각각 끌 수 있다.
