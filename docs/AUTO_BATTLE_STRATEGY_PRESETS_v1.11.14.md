# Auto Battle Strategy Presets v1.11.14

## 프리셋

- 공격형: 위협 타겟 우선, 자동 스킬 적극 사용, 보스전 전체 자동, 모든 패턴 회피, 즉시 자동 복귀
- 균형형: 공격·회피·Drive 보존을 균형 있게 운용
- 보존형: 낮은 HP 타겟 우선, Drive와 스킬을 아끼고 안정형 반응과 지연 복귀 사용
- 사용자 설정: 프리셋 적용 후 세부 옵션을 직접 변경한 상태

## 저장 규격

- `lumerift.combatAssist.v4`
- v3·v2·v1 저장값을 읽어 현재 세부 설정과 일치하는 프리셋을 추론한다.
- 자동 타겟과 자동 전투 ON/OFF는 프리셋 전환 시 유지한다.

## 전투 판단

프리셋은 스킬 사용에 필요한 Drive 하한, 마무리 공격 보존 기준, 스킬 사용 대상 HP 하한, 선호 거리 계산에 반영된다.
