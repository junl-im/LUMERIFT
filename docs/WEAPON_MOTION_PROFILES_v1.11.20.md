# Weapon Motion Profiles v1.11.20

장착 무기 실루엣에 따라 기본 공격과 스킬의 체감 타이밍을 분리한다.

## 균열검

- 빠른 공격 준비와 회수
- 연속 입력 반응 우선
- 짧은 전진 거리 보강

## 대검

- 느린 준비와 넓은 공격각
- 기본 공격과 스킬 피해·타격 정지 강화
- 3타 마무리 공격의 중량감 강화

## 균열 장창

- 좁은 공격각과 긴 사거리
- 전진 거리와 선제 타격 시점 강화
- 안전 거리에서 정밀 압박

## 구현

- `src/game/combat/WeaponMotionProfile.ts`
- 원본 전투 데이터를 변경하지 않고 전투 진입 시 불변 복사본을 생성
- 장착 무기 계열은 `CharacterEquipmentVisualProfile`과 동일한 계산을 사용
- 텔레그래프·충돌·피해 범위는 조정된 액션 데이터로 동일하게 계산되며 `AttackFootprint` 단일 판정 구조를 유지
