# Premium Character Runtime Second Pass — v1.11.30

v1.11.30은 승인된 Premium Art Direction v2를 실제 전투와 캐릭터 스튜디오에 더 깊게 적용하는 프로그램형 2차 제작 단계다.

- 얼굴 림라이트·크레스트, 전·후면 헤어, 갑주 플레이트·트림, 망토 원단·테두리, 흉부 룬 코어를 독립 레이어로 구성한다.
- 검은 정밀 연격, 대검은 중량 절단, 균열 장창은 직선 관통 실루엣을 사용한다.
- 장비 교체 전·후 미리보기와 전투가 동일한 외형 계약을 공유한다.
- 기존 본체 Atlas는 안전 폴백으로 유지하며 최종 수작업 Atlas 완성을 주장하지 않는다.
- Player Save v4와 AttackFootprint 계약은 변경하지 않는다.
