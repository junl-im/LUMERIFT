# AUTO_COMBAT_SESSION_REPORT_v1.11.11

## 목적
자동 전투가 현재 무엇을 하는지뿐 아니라 한 전투 동안 어떤 판단을 얼마나 수행했는지 남긴다.

## 기록 항목
- 자동 전투 활성 시간
- 자동 타겟 변경 횟수
- 기본 공격·스킬 1·스킬 2·회피 실행 횟수
- 수동 이동 또는 직접 액션 개입 횟수
- 보스 패턴별 자동 회피 횟수
- 가장 자주 발생한 판단 이유와 최근 판단 이유

## 결과 화면
`ResultScene`의 `AUTO ASSIST REPORT` 패널에 핵심 통계를 표시한다.
저장 데이터 스키마는 변경하지 않으며 전투 결과 객체에만 선택적으로 포함한다.
