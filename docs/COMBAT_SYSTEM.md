# LUMERIFT Combat System v0.3

## 1. 전투 데이터 원칙

전투 수치와 적 배치는 JSON에서 정의한다. PixiJS 화면 코드는 수치를 소유하지 않고 검증된 런타임 데이터를 표시한다.

- 액션: `src/data/actions.json`
- 플레이어: `src/data/player.json`
- 몬스터: `src/data/monsters.json`
- 스테이지: `src/data/stages.json`
- 검증: `src/game/data/GameDataRegistry.ts`

## 2. 플레이어 상태

- `idle`
- `moving`
- `attacking`
- `skill`
- `dodging`
- `hit`
- `dead`

3연속 기본 공격, 스킬 2종, 방향 회피, 무적 프레임을 유지한다.

## 3. 스테이지 웨이브

`stage_001`은 3개 웨이브로 구성된다.

1. 일반 균열 추적자 3마리
2. 파수병·추적자·정예 감시자
3. 보스 심연의 전령

한 웨이브의 적이 모두 사망하면 JSON의 `spawnDelay` 후 다음 웨이브를 생성한다.

## 4. 몬스터 FSM

```text
idle
→ chase
→ telegraph
→ attack
→ chase
```

피격 시 `hit`, HP가 0이면 `dead`로 전환한다.

`telegraph` 상태에서는 실제 피해 판정 전에 공격 범위를 표시한다. 범위가 표시되기 전에 피해를 주지 않는다.

## 5. 정예 패턴

균열 감시자는 다음 패턴을 순서대로 사용한다.

- 감시자 절단: 전방 부채꼴
- 균열 파동: 자신 중심 원형 범위

## 6. 보스 패턴

심연의 전령은 다음 3개 패턴을 순환한다.

- 심연 절단: 전방 넓은 부채꼴
- 심연 폭발: 보스 중심 대형 원형 범위
- 추적 균열: 시전 시작 시 플레이어 위치를 고정한 원형 공격

보스 공격은 일반 몬스터보다 긴 Telegraph를 사용한다.

## 7. 상태 이상

### 화상

- 일정 간격으로 지속 피해
- 루멘 크래시가 기본 적용 수단
- 같은 화상 재적용 시 남은 시간과 강도를 갱신

### 둔화

- 몬스터 이동속도 감소
- 섬광 베기 II와 리프트 노바가 적용 가능
- 최소 이동속도는 기본 속도의 20%

### 저항

- 일반 몬스터: 지속시간 100%
- 정예: 지속시간 75%
- 보스: 지속시간 50%

## 8. 일시정지

`P`, `Esc` 또는 HUD 버튼으로 일시정지한다.

정지 중에는 다음 항목이 멈춘다.

- 캐릭터 이동과 공격
- 몬스터 AI
- 쿨다운
- 상태 이상 시간
- 카메라와 전투 이펙트
- 전투 기록 시간

## 9. 그래픽 품질

- 고품질: 전체 장식·이펙트·카메라 흔들림
- 균형: 기본 권장값
- 절전: 장식과 이펙트 감소, 카메라 흔들림 축소

게임 규칙과 피해량은 품질 설정에 영향을 받지 않는다.
