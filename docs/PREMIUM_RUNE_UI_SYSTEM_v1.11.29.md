# LUMERIFT 룬 VFX·금속 유리 UI 시스템 · v1.11.29

## 룬 VFX

기존 효과 Atlas 위에 충격 등급별 프로그램형 룬을 합성한다.

- Light: 6개 광선·1개 링
- Heavy: 8개 광선·2개 링·육각 코어
- Ultimate: 12개 광선·3개 링·왕관형 코어
- 낮은 그래픽 품질에서는 효과 밀도 0.42 이하일 때 추가 룬을 생략
- `AttackFootprint`와 실제 피해 판정은 변경하지 않음

## 공통 UI

모든 공통 패널과 버튼에 다음 프레임 언어를 추가했다.

- 바깥쪽 소프트 골드 금속선
- 안쪽 블루·바이올렛 유리선
- 대각 모서리 장식과 중앙 룬 포인트
- 작은 리소스 칩은 장식을 축소해 가독성 유지
- 기존 48px 최소 터치 영역과 v5 UI Atlas 유지

이번 변경은 신규 대형 UI 이미지를 추가하지 않는 프로그램형 업그레이드라 초기 다운로드 증가가 없다.
