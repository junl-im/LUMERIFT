# 모바일 전투 회귀 계약 v1.11.4

## 자동화된 순수 로직 범위

- 단일 포인터 행동 소유권과 중복 탭 차단
- 진동 반복 제한과 사용자 비활성화
- 치명타·스킬·정밀 회피 음향 레이어 구성
- QA 세션 안정성 점수와 30/60 FPS 권장값
- 전용 도색 후보 선택·지속 저장·기본 원화 복귀

## 실브라우저 대기 범위

Playwright 의존성은 현재 프로젝트에 포함하지 않는다. GitHub Actions 또는 실제 기기에서 다음을 수동/후속 E2E로 확인한다.

- Android Chrome과 Samsung Internet 멀티터치
- iOS Safari 진동 미지원 시 무오류 폴백
- VoiceOver·TalkBack 보스 경고 낭독 순서
- 오디오 자동 재생 해제 후 다층 효과음
- 20분 QA 세션 JSON 다운로드
