# v1.11.7 자동 타겟팅·자동 전투

## 자동 타겟팅
- 기본값: ON
- 평가 요소: 거리, 캐릭터 전방 각도, 보스/엘리트 우선도, 공격 예고 상태, 잔여 HP
- 타겟 스위칭 히스테리시스를 적용해 매 프레임 타겟이 흔들리지 않게 한다.
- 화면에서 적을 직접 터치하면 해당 적을 우선 잠금할 수 있다.
- 전투 HUD의 `TARGET` 버튼 또는 설정 화면에서 켜고 끌 수 있다.

## 자동 전투
- 기본값: OFF
- 자동 전투를 켜면 자동 타겟도 자동으로 켜진다.
- 행동 우선순위:
  1. 임박한 텔레그래프 회피
  2. 타겟까지 거리 조절
  3. 스킬 2 우선 조건 확인
  4. 스킬 1 사용
  5. 기본 공격과 콤보 연결
- 수동 조이스틱·키보드 이동은 자동 이동을 즉시 중단한다.
- 수동 버튼 입력과 플레이어 상태가 자동 행동보다 우선한다.
- 튜토리얼 중에는 자동 전투가 개입하지 않는다.

## 안전 계약
- 자동 전투는 클라이언트 편의 기능이며 서버 권위 판정이나 랭킹 점수 생성에 사용하지 않는다.
- 충돌, 피해, 치명타, 드롭, 보스 AI, AttackFootprint는 변경하지 않는다.
- 자동 기능 OFF 상태에서 기존 수동 플레이와 동일하게 동작해야 한다.
