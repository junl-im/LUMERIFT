# v1.11.6 8방향 이동 그래픽 강화

## 목표
- 캐릭터 8방향 이동이 눈에 띄게 더 자연스럽고 읽기 쉬워 보이도록 polish한다.
- 신규 대용량 원화 없이 기존 Atlas와 Graphics 계층으로 디테일을 끌어올린다.

## 적용 내용
- `PlayerActorView`에 `smoothedFacing`을 도입해 급격한 방향 전환 시 무기·장비·실루엣 반응을 부드럽게 만들었다.
- 방향 리본(`directionRibbon`)을 추가해 현재 진행 방향을 자연스럽게 강조했다.
- 발자국 하이라이트(`stepHighlights`)를 추가해 보행/대시 시 움직임 리듬을 읽기 쉽게 만들었다.
- 그림자와 실루엣에 보조 광택을 추가해 캐릭터 존재감과 방향성을 높였다.
- `PlayerMotionDirector`의 이동 리듬을 조정해 보행 bounce, 어깨 리듬, 미세 회전 표현을 강화했다.

## 유지 계약
- 이동 입력, 충돌, 공격 판정, 피해 계산, AI 로직은 변경하지 않는다.
- 8방향 Atlas 키 계약과 미러링 규칙을 유지한다.
- reduced motion 사용 시 과도한 이동 연출을 유발하지 않는다.

## 다음 감수
- 실브라우저 safe area와 HUD 정렬 검수
- 8방향 공격 성공 프레임·타격 포즈 보정
- 장시간 플레이에서 잔상/시각 피로 확인
