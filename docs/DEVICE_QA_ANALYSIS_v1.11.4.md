# 실기기 QA 자동 분석 v1.11.4

QA JSON 스키마를 `lumerift-device-qa-v3`로 올리고 기록 세션에 자동 분석 결과를 포함한다.

## 판정 항목

- 화면이 실제로 보인 표본과 숨겨진 표본 분리
- 평균 FPS 대비 목표 FPS 비율
- 1% Low 대비 목표 FPS 비율
- 33ms·50ms 이상 프레임 비율
- 최대 P99 프레임 시간
- 안정 우선 렌더 단계 사용 비율
- 품질 단계 전환 횟수
- 지원 브라우저의 20분 환산 배터리 감소율

## 결과

- 안정성 점수 0~100
- 매우 안정·안정·제약 있음·불안정·표본 부족 등급
- 낮음·중간·높음 신뢰도
- 30/60 FPS 권장값
- 높음·중간·낮음 그래픽 권장값
- 문제 원인과 강점 목록

표면 온도와 GPU 메모리는 브라우저 추정으로 채우지 않으며 물리 측정값으로 남긴다.
