# LUMERIFT v0.2.0 Patch Notes

## 핵심 변경

- 게임 이름을 `LUMERIFT: 균열의 계승자`로 확정
- 전투 프로토타입을 단일 공격 테스트에서 실제 액션 루프로 확장
- 3연속 기본 공격과 입력 예약
- 루멘 크래시, 리프트 노바 추가
- 회피, 무적 프레임, 쿨다운 추가
- 플레이어 상태기계 추가
- 몬스터 FSM 및 몬스터 공격 추가
- HP, 패배, 전투 결과 저장 추가
- Hit Stop, Shake, Zoom Pulse 추가
- 히트 판정과 전투 로직 단위 테스트 추가

## 호환성

기존 `rpg.*` LocalStorage 값은 읽기 호환을 유지하며 새 `lumerift.*` 키로 이전한다.
