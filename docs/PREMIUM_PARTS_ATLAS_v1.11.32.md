# Premium Parts Atlas v1.11.32

## 플레이어

512×512 투명 WebP에 16개 래스터 파츠를 배치한다. 전후면 헤어, 얼굴 크레스트, 어깨·흉부 갑주, 망토 원단·테두리, 룬 코어, 검·대검·장창, 가드·충격·오라가 포함된다. `PremiumCharacterDetailLayerView`가 기존 v10/v11 본체 위에 합성하며, Atlas가 없으면 기존 Graphics 레이어가 그대로 작동한다.

## 몬스터

Void·Frost·Inferno 엘리트와 Abyssal 보스용 크레스트·코어·발톱·갈기·꼬리·오라를 16개 파츠로 제공한다. `PremiumMonsterDetailLayerView`는 기존 v4 몬스터 본체를 유지하며 엘리트·보스 판독성만 강화한다.

## 완료 정의

이번 배치는 승인 아트 방향을 실제 전투에 가져오는 첫 래스터 파츠 배치다. 8방향 전체 전신·공격 애니메이션이 모두 수작업 교체된 최종 Atlas가 아니다.
