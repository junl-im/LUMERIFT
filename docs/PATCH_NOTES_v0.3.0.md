# LUMERIFT v0.3.0 Patch Notes

## 적용 기준

- 기준 버전: v0.2.0
- 대상 버전: v0.3.0
- 패치 ZIP은 기존 프로젝트 루트에 그대로 풀어 덮어쓴다.
- 삭제 파일은 `PATCH_DELETE_LIST.txt`를 확인한다.

## 주요 변경

- 전투 데이터 JSON화
- 3개 웨이브
- 정예 몬스터
- 보스 3패턴
- 화상·둔화
- 일시정지
- 그래픽 품질
- Atlas 샘플과 검증

## 적용 후 확인

```bash
npm install
npm run verify
npm run dev
```

로비에서 `3웨이브 전투 시작`을 선택한 뒤 WAVE 1 → ELITE WAVE → BOSS 흐름을 확인한다.
