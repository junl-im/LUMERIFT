# LUMERIFT 플레이어 도색 후보 v1.11.3

## 목적

v1.11.2 기하형 8방향 모션의 방향·피벗·행동 판독성을 유지하면서 모바일 전투에서 더 선명하게 보이는 1차 도색 후보를 만든다.

## 적용

- 2048×1024 RGBA 제작용 PNG 마스터
- 128×128 셀 128개, 8방향·80 애니메이션 키 유지
- 청록 외곽 광, 남색 실루엣 경계, 금속 명암, 금색 장식, 피격 산호색 분리
- `player-owned-painted` Lazy Loading 번들로만 제공
- 기본 캐릭터는 기존 고급 `detail` Atlas 유지
- 로딩 실패 시 고급 기본 원화로 자동 복구

## 품질 한계

이 자산은 모션·색·가독성 검수용 도색 후보이며 최종 수작업 캐릭터 원화가 아니다. 사용자 승인 전 기본 Atlas로 승격하지 않는다.
