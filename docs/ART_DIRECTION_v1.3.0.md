# LUMERIFT 전용 캐릭터·몬스터 아트 제작 규격 v1.3.0

이 문서는 공개 라이선스 임시 아트를 LUMERIFT 전용 원화로 교체하기 위한 제작 계약이다. 현재 자산을 최종 원화로 간주하지 않는다.

## 플레이어

- 시점: 2.5D 쿼터뷰, 카메라 기준 35~45도
- 방향: N, NE, E, SE, S, SW, W, NW 8방향
- 기준 셀: 256×256 WebP 런타임, 512×512 모바일 제작용 마스터
- 중심축: 발 중앙 고정, 프레임 간 피벗 이동 2px 이하
- 실루엣: 한 손 균열검, 비대칭 어깨 장갑, 청록 루멘 코어
- 색 역할: 흑청색 갑주 60%, 은색 20%, 청록 발광 12%, 금색 계승 문양 8%
- 조명: 좌상단 주광, 청록색 하단 균열 반사광

### 필수 모션

- Idle 6프레임
- Run 8프레임
- Attack 1~3 각 8프레임
- Skill 1~2 각 10프레임
- Hit 4프레임
- Dodge 6프레임
- Death 10프레임

## Chapter 1 몬스터

- 일반 5종: 오염된 생체·균열 결정의 결합
- 정예 2종: 일반 실루엣 재색칠이 아니라 별도 장비·돌기·발광 구조
- 보스 1종: 3페이즈에서 실루엣과 발광 면적이 단계적으로 변화
- 동일 광원과 외곽선 두께 사용
- 플레이어보다 채도를 낮추고 위험 부위만 적색·보라색으로 강조

## 런타임 계약

- 기존 `player.{state}.{direction}` 키 유지
- 기존 `monster.{id}.{state}` 키 유지
- PNG/WebP만 사용, SVG 금지
- 한 Atlas 최대 4096×4096
- 모바일 GPU 업로드 후 장면 종료 시 해제

## 완료 판정

원화·리깅·Atlas·실기기 60FPS·저작권 확인·아트 디렉터 승인을 모두 통과하기 전에는 `final-approved`로 기록하지 않는다.
