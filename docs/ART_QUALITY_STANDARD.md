# LUMERIFT 아트 품질 기준

## 품질 단계

| 단계 | 의미 | 최종급 표현 허용 |
|---|---|---|
| prototype | 기능 검증용 임시 자산 | 금지 |
| production-structure | 경로·Atlas·성능 구조 검증 | 금지 |
| production-candidate-procedural | 고해상도 절차형 제작 후보 | 금지 |
| final-candidate | 수작업 리터칭·아트 검수·실기기 검수 완료 | 제한적 허용 |
| final-approved | 저작권·아트 디렉션·성능 QA 최종 승인 | 허용 |

## final-candidate 승격 조건

- 캐릭터 얼굴·손·무기 연결 수작업 검수
- 동일 직업·세력·지역의 재질과 비율 통일
- 9:16 실제 화면에서 축소 가독성 확인
- 색약·명암·UI 대비 검수
- WebP 압축 후 경계와 밴딩 확인
- Android Chrome·iOS Safari 메모리·FPS 확인
- 저작권과 유사성 확인
- 아트 디렉터 또는 지정 검수자의 승인 기록

## 보고 진실성

파일 수, 해상도, 용량이 크다는 이유만으로 AAA 또는 최종 품질이라고 표현하지 않는다. 릴리스 보고서에는 반드시 현재 품질 단계와 알려진 한계를 함께 기록한다.
