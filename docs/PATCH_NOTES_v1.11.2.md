# LUMERIFT v1.11.2 패치 노트

- LUMERIFT 소유 플레이어 8방향 모션을 선택형 런타임 Atlas로 1차 승격
- 기존 고급 플레이어 원화를 기본값으로 유지하고 전용 미리보기는 Lazy Loading
- 서쪽 방향 실제 프레임과 기본 미러링 정책 분리
- 3초 간격 실기기 QA 세션 기록, 프레임·품질·뷰포트·배터리 요약 추가
- QA JSON 스키마 v2 및 물리 온도·GPU 메모리 미측정 정책 명시
- 설정 화면에 캐릭터 원화 선택과 QA 기록 시작·종료 UI 추가
- 전용 Atlas 실패 시 기존 플레이어 Atlas 자동 복구
- v1.11.2 전용 자산·세션·런타임 연결 검증 추가
