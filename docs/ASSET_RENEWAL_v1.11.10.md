# ASSET_RENEWAL_v1.11.10

## 요약
v1.11.10은 런타임 이미지 대량 교체보다는 **에셋 인지 구조**를 개선한 버전이다.
실사용 번들과 레거시/보관 자산의 구분을 화면에서 더 직관적으로 드러내도록 Asset Gallery UI를 보강했다.

## 적용 포인트
- 에셋 보관소 상단에 production-line 태그 추가
- 라이브 아트와 레거시 아카이브를 설명하는 피처 마키 추가
- 카테고리/페이지 정보의 시각적 계층 강화
- 모바일 제작용 마스터와 배포용 런타임의 역할 분리를 문서에 재강조

## 후속 과제
- v1.11.11에서 전용 공격 궤적 아트 및 보스 예외 데이터 문서 연계
- 실제 스크린샷 기반 Asset Gallery QA 캡처 보강
