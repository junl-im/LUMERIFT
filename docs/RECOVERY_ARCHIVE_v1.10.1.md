# 시즌·복구 JSON v1.10.1

## 포함 데이터

- 현재 Player Save v4
- 최대 5개 로컬 복구 지점
- 현재 28일 시즌 ID·기간
- 레벨, 최고 스테이지, 골드, 클리어 수, 처치 수 시즌 스냅샷
- 앱 버전과 내보낸 시각

스키마 ID는 `lumerift-recovery-archive-v1`이다.

## 안전 규칙

- 현재 로그인 UID와 JSON의 UID가 다르면 가져오기를 거부한다.
- 가져오기 직전에 `JSON 가져오기 전` 복구 지점을 자동 생성한다.
- 가져온 저장은 먼저 로컬에만 적용한다.
- Cloud Save 덮어쓰기는 계정 화면의 `로컬 → 클라우드`에서 사용자가 직접 선택한다.
- 알 수 없는 필드는 Player Save v4 마이그레이션 과정에서 제거된다.

JSON은 보안 토큰이나 Firebase 자격 증명을 포함하지 않는다. 하지만 진행 데이터와 UID가 들어 있으므로 공개 게시하지 않는 것을 권장한다.
