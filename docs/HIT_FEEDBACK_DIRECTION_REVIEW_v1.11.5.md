# v1.11.5 방향 시각 검수·타격 피드백

## 방향 검수
- ATTACK VECTOR 패널이 현재 입력/시선 방향을 상·하·좌·우 및 대각선 기준으로 텍스트 표시한다.
- 공격이 발동되면 콘/원형 판정에 방향선과 화살촉을 추가해 눈으로 읽기 쉬운 형태로 보강한다.
- 조이스틱은 8방향 가이드와 heading needle을 사용한다.

## 타격 피드백
- 일반 피해: 숫자 중심 표시
- 플레이어 피격: `HIT` 다층 텍스트
- 화상/지속 피해: `BURN` 다층 텍스트
- 치명타: `CRIT` 다층 텍스트와 별도 배너
- 다중 명중/치명타 시 `CHAIN SLASH`, `CRITICAL CUT`, `CRITICAL RUSH` 배너 출력

## 검수 포인트
- 숫자 표시는 가독성을 우선하며 지나친 플래시는 접근성 옵션과 충돌하지 않아야 한다.
- 크리티컬 연출은 강하지만 보스 장판 정보보다 우선하지 않도록 지속 시간을 짧게 유지한다.
