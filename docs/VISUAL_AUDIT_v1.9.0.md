# VISUAL AUDIT v1.9.0

## 점검 결과

v1.8.1까지 기능은 연결됐지만 첫 화면과 각 장면이 서로 다른 시기의 패널·버튼·간격을 사용했다. 로그인은 기능형 화면, 로비는 카드 대시보드, 전투는 별도 HUD, 계정은 또 다른 관리 화면처럼 보여 하나의 게임으로 느껴지는 연결성이 부족했다.

## 발견한 문제와 조치

| 영역 | 이전 문제 | v1.9.0 조치 |
|---|---|---|
| 첫 화면 | 게임 정체성과 주요 로그인 경로가 약함 | 전용 타이틀 배경과 게임 시작 중심 구조 적용 |
| 공통 패널 | 화면마다 테두리·반경·색이 다름 | v5 NineSlice Atlas로 통일 |
| 버튼 | 텍스트만 있는 버튼과 임시 버튼 혼재 | 아이콘·부제·정렬 지원 공통 버튼 적용 |
| 로비 | 메뉴와 퀘스트가 동일한 카드 강도로 경쟁 | 캐릭터·전투 시작·일일 정보·보조 메뉴 순으로 재구성 |
| 전투 | 하단 조작부가 배경과 섞임 | 반투명 컨트롤 도크와 조작 안내 추가 |
| 인벤토리 | 기능은 있으나 다른 화면과 질감 단절 | 공통 탭·슬롯·패널·장면 헤더 적용 |
| 계정/운영 | 관리 기능 위주의 업무 화면 인상 | 공통 판타지 패널과 상태색, 주 행동 계층 적용 |
| 모바일 | 노치·주소창·가상 키보드와 일부 겹침 위험 | 기존 Safe Area·100dvh·visualViewport 계약 유지 |

## 실제 적용과 시안의 구분

- 실제 적용: v5 UI Atlas, v5 아이콘 Atlas, 타이틀 배경, Boot/Login/Lobby 코드, 공통 SceneChrome, UiButton, 전투 컨트롤 도크.
- 공통 스킨으로 개선되는 기존 화면: 스테이지, 결과, 인벤토리, 퀘스트, 운영, 계정, 랭킹, 복구.
- 디자인 시안: `docs/previews/v1.9.0_*_concept.webp`. 시안은 방향과 밀도 검토용이며 런타임 스크린샷으로 주장하지 않는다.
- 현재 캐릭터·몬스터 원화는 공개 라이선스 원본의 통일 보정 단계이며 독점 최종 원화가 아니다.

## 남은 검수

- Android Chrome과 iOS Safari에서 360×640~430×932 실기기 터치 영역 확인
- 한국어 시스템 폰트별 글자 잘림 확인
- Google 로그인 팝업 차단·가상 키보드 표시 시 계정 팝업 확인
- 저사양 WebGL 기기에서 타이틀 배경 및 NineSlice 드로우콜 확인
- 전투 중 HUD 가독성과 색약 모드 추가 검토
