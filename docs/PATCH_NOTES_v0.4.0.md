# LUMERIFT v0.4.0 Patch Notes

## 주요 변경

- 장비 정의 9종
- 무기·방어구·장신구
- 일반·희귀·영웅
- 인벤토리 화면
- 장착·강화·잠금·판매
- 필터·정렬·일괄 판매
- 전투 장비 드롭
- 장비 능력치 전투 반영
- 저장 데이터 v2와 v1 자동 마이그레이션

## 누적 패치 기준

최종 제공되는 덮어쓰기 패치는 사용자가 마지막으로 전달받은 v0.1.0을 기준으로 v0.4.0까지의 모든 변경 파일을 포함한다.

## 적용 후 확인

```bash
npm install
npm run verify
npm run dev
```

1. 로비에서 스타터 장비와 전투력 확인
2. 장비·인벤토리 진입
3. 강화 후 골드 감소와 전투력 증가 확인
4. 전투 클리어 후 장비 드롭 확인
5. 장비 장착 후 전투 HP·공격·방어 증가 확인
