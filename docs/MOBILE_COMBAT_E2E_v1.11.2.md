# 모바일 전투 E2E 회귀 행렬 v1.11.2

| 시나리오 | 기대 결과 |
|---|---|
| 조이스틱 유지 중 공격·스킬 동시 입력 | 각 버튼은 단일 pointerId만 소유하고 중복 행동이 발생하지 않는다. |
| 회피 버튼 pointercancel | 눌림 상태가 남지 않고 다음 회피 입력이 정상 처리된다. |
| 보스 장판 예고→위험→회피 | 동일 AttackFootprint를 사용하며 기호·패턴명·타이밍 눈금이 갱신된다. |
| 전용 모션 미리보기 선택 후 전투 진입 | Lazy Loading Atlas가 사용되고 서쪽 방향이 추가 미러링되지 않는다. |
| 전용 Atlas 로딩 실패 | 기존 고급 플레이어 Atlas로 자동 복구한다. |
| QA 기록 중 화면 회전·백그라운드 전환 | 방향·visibility 변경 횟수와 뷰포트 표본이 JSON에 기록된다. |
| QA 종료 후 JSON 저장 | 세션 요약·배터리 지원 여부·물리 측정 null 정책이 포함된다. |
