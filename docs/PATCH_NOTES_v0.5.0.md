# LUMERIFT v0.5.0 Patch Notes

## 추가

- 스테이지 선택 화면
- 챕터 1 스테이지 10개
- 잠금·해금과 권장 전투력
- 최초 클리어·반복 보상
- 최고 기록과 클리어 횟수
- 일반 5종·정예 2종·보스 1종 MVP 몬스터 구성
- 메인 퀘스트 6종과 일일 퀘스트 3종
- 퀘스트 조건 추적과 보상 수령
- 1-1 인터랙티브 전투 튜토리얼
- 스테이지 구간별 아레나 색상 변형
- 저장 데이터 v3

## 변경

- 로비의 전투 시작을 스테이지 작전도로 교체
- 전투 결과에서 재도전·다음 스테이지·작전도 이동 지원
- 장비 강화가 메인·일일 통계에 반영
- 버전을 v0.5.0으로 갱신

## 알려진 제한

- 맵 배경은 시스템 검증용 색상 변형이며 최종 WebP 타일 아트가 아니다.
- 튜토리얼은 1-1 조작 흐름 중심이며 대화·연출형 튜토리얼은 이후 적용한다.
- 실제 npm 설치, Vite 빌드와 브라우저 실기동은 네트워크 가능한 사용자 환경에서 최종 확인해야 한다.
