# LUMERIFT v1.11.29 패치 노트

## 캐릭터 중심 런타임 제작 1차

- Premium Art Direction v2 기준의 금속 트림·얼굴 크레스트·흉부 룬·망토 윤곽을 전투 플레이어에 합성했다.
- 검·대검·균열 장창마다 무기 룬의 길이·폭·끝 형태를 분리했다.
- 8방향·3개 무기 계열·10개 행동·6개 레이어의 최종 제작 규격을 고정했다.
- 계획 본체 프레임은 1,752개이며 최종 수작업 Atlas 완료로 기록하지 않는다.

## 엘리트·보스

- 엘리트와 보스에 왕관형 크리스털, 약점 코어, 발톱 실루엣을 추가했다.
- 보스 코어는 페이즈와 공격 전조에 맞춰 크기·회전·발광이 달라진다.
- 엘리트 3종과 보스 1종, 총 936프레임의 차기 Atlas 계획을 등록했다.

## 룬 VFX·UI

- Light·Heavy·Ultimate 충격 등급별 룬 복잡도를 6/8/12광선, 1/2/3링으로 분리했다.
- 기존 VFX Atlas 위에 룬을 합성하며 낮은 품질에서는 자동 생략한다.
- 모든 공통 패널과 버튼에 이중 금속·유리 프레임과 룬 포인트를 적용했다.
- 신규 런타임 이미지는 0개이며 초기 번들 증가도 0 bytes다.
