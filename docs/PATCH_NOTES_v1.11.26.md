# LUMERIFT v1.11.26 패치 노트

## 외형 충돌 3열 미리보기

- 로컬, Cloud, 최종 병합 결과를 동일한 Pixi 캐릭터 렌더러로 나란히 표시한다.
- 선택 슬롯의 장비 외형, 염색, 방향, 포즈, 코스튬, 세부 채널을 실제 결과 Archive 기준으로 확인한다.
- 고정 슬롯 때문에 요청 선택과 실제 적용 출처가 달라지는 경우 이를 결과 출처로 표시한다.

## 30분 1회 실행 취소

- 충돌 병합 직전 로컬 Archive를 UID별 Undo 지점으로 저장한다.
- Undo는 생성 후 30분 동안 한 번만 사용할 수 있다.
- 실행 취소 직전 현재 병합 상태도 일반 복구 지점으로 남긴다.
- Cloud 동의와 연결 상태가 유효하면 복원본을 Cloud에 재업로드하고, 그렇지 않으면 로컬만 복원한다.

## 복구 저장소 v2

- 복구 지점 이름 변경, 검색, 고정을 지원한다.
- UID별 고정 지점 최대 3개와 최근 지점 최대 5개를 별도로 유지한다.
- v1 복구 지점과 Archive는 이름·고정 기본값을 부여해 v2로 마이그레이션한다.

## 유지 계약

- Player Save v4, AttackFootprint, App Check 비활성 정책을 변경하지 않는다.
- 신규 런타임 이미지를 추가하지 않는다.
- 물리 기기 캡처와 최종 수작업 원화를 완료로 주장하지 않는다.
