# v1.11.5 전투 HUD 대정리

## 핵심 구조
1. 상단 좌측: HERO CUT 플레이어 카드 + HP 바
2. 상단 중앙: SCENE 카드 + Wave / Enemy count
3. 상단/중앙: 보스 패널과 긴급/연출 문구
4. 중앙 상단: HYPE METER와 DRIVE 게이지
5. 하단 좌측 상단: ATTACK VECTOR 패널
6. 하단: 입력 도크 + 이동/회피/스킬/공격 버튼

## 개선 포인트
- 기존 HUD보다 정보 묶음을 더 명확히 분리
- 전장 상태와 입력 상태를 분리해 가독성 향상
- 배너형 피드백을 추가해 공격 성공/크리티컬 체감 강화
- 모바일 한 손 플레이에서도 각 버튼 의미가 잘 보이도록 역할 배지 추가

## 주의
- HUD 재배치가 판정 로직·AI·쿨다운 수치·드롭 보상에 영향을 주지 않아야 한다.
