# LUMERIFT v1.11.28 패치 노트

## Premium Art Direction v2

- 사용자가 승인한 캐릭터 품질 쇼케이스를 차기 플레이어·장비 제작 기준선으로 등록했다.
- 동일한 비주얼 언어로 제작한 몬스터 품질 쇼케이스를 몬스터·보스 제작 기준선으로 등록했다.
- 블루·바이올렛·실버·소프트 골드 팔레트와 금속·천·크리스털·룬 재질 언어를 UI·스킬·장비까지 확장하는 규칙을 고정했다.
- 캐릭터·몬스터·UI·스킬 VFX·장비 5개 도메인의 가중 품질 게이트를 추가했다.
- 모바일 판독성이 80점 미만이면 고해상도나 효과 품질과 관계없이 승인되지 않도록 했다.

## 에셋 보관소

- `확정 비주얼 기준 · 캐릭터 & 몬스터` 분류를 첫 항목으로 추가했다.
- 승인 이미지 2종을 에셋 보관소에서 직접 비교할 수 있다.
- 두 이미지는 Lazy Reference 번들로만 로딩되며 게임 시작·로비·전투 번들에는 포함되지 않는다.
- 런타임 감수용 WebP와 재가공용 고품질 WebP 마스터를 분리했다.

## 용량

- 신규 런타임 감수 이미지 2개
- 런타임 감수 이미지 합계 668,606 bytes
- 초기 다운로드 번들 증가 0 bytes
- 신규 이미지는 전투용 Atlas가 아니라 비주얼 제작 기준을 위한 지연 로딩 참고 자산이다.
