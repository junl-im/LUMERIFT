# Premium Monster Variants — v1.11.30

엘리트와 보스가 동일한 장식만 공유하지 않도록 개체별 프로그램형 실루엣을 분리했다.

- Void Warden: 5개 크레스트, 중량 어깨 결정, 청록 약점 코어.
- Lumen Mender: 치유형 왕관과 다중 위상 파편, 황금 코어.
- Abyssal Harbinger: 7개 크레스트, 10개 위상 파편, 페이즈 반응형 왕관·약점 코어.
- 일반 몬스터는 기존 판독성을 보존하고 엘리트·보스에만 강화 레이어를 표시한다.
- 최종 수작업 몬스터 Atlas는 후속 제작 항목이다.
