# LUMERIFT v1.1.0 패치 노트

## 모바일 제작용 원본 최적화

LUMERIFT 소유의 절차형 제작 원본은 모바일 웹게임 제작에 필요한 범위를 넘어서는 해상도와 비압축 PNG 상태로 보관되고 있었다. v1.1.0에서는 런타임 품질에 영향을 주지 않는 범위에서 원본을 용도별 제작 해상도로 축소하고 PNG를 재압축했다.

- 키아트: 최대 1080×1920
- 영웅 전신: 최대 768×1152
- 보스 초상: 최대 768×768
- NPC 초상: 최대 576×768
- 아이템 제작 시트: 최대 1536×1536
- 스킬 제작 시트: 최대 1536×960
- UI 제작 시트: 최대 1920×1440
- 공개 라이선스 제3자 원본: 출처·재가공 근거 보존을 위해 원본 상태 유지

`art_source`는 약 502.76MB에서 약 76.46MB로 감소했다.

## UI 2차 리빌드

- 인벤토리: 등급별 실제 슬롯 프레임, 장착 배지, 강화 진행률, 전투력·골드·장비 보너스 카드
- 스테이지 선택: 캠페인 진행률, 노드 경로선, 선택 상태 배지, 권장 전투력 준비도
- 결과 화면: 랭크 메달, 처치·콤보·시간 카드, 금속 보상 패널

## BAT 정책

`INSTALL_AND_START.bat`와 `VERIFY.bat`는 Windows 사용자를 위한 선택 편의 도구다. npm 명령과 GitHub Actions가 실제 기준이며 BAT 파일은 필수 구성요소가 아니다.
