# LUMERIFT v1.11.25 Patch Notes

## 외형 Cloud 충돌 비교·선택 병합

- 로컬과 Cloud 외형 Archive의 슬롯 1·2·3 차이를 이름·염색·포즈·방향·세트·염색 채널 단위로 요약한다.
- 각 슬롯은 로컬·Cloud·최신 저장값 중 하나를 선택할 수 있다.
- 슬롯 순서, 고정 상태, 최근 프리셋은 별도 항목으로 선택한다.
- 최근 프리셋 선택 병합은 동일 외형 중복을 제거하고 즐겨찾기를 보존하며 최신 저장값을 우선한다.
- 로컬에서 고정한 슬롯의 내용은 Cloud 선택 시에도 강제로 덮어쓰지 않는다.

## 외형 복구 지점

- Cloud 업로드와 충돌 병합 전에 현재 로컬 외형 Archive를 자동 백업한다.
- 수동 백업과 복구 적용 전 재백업을 지원한다.
- 로그인 UID별 최대 5개 복구 지점을 보관한다.
- 복구 묶음 JSON 내보내기·가져오기를 지원하며 UID가 다른 JSON은 거부한다.
- 복구 적용 후에는 Cloud에 자동 업로드하지 않아 사용자가 결과를 확인할 수 있다.

## 검증과 유지 계약

- Player Save v4와 외형 Archive v3는 계속 분리한다.
- AttackFootprint 단일 전투 판정을 유지한다.
- Firebase App Check 비활성 결정을 유지한다.
- 신규 런타임 이미지는 추가하지 않았다.
- 실제 Android·iOS 캡처와 최종 수작업 공격·장비 원화는 완료로 기록하지 않는다.
