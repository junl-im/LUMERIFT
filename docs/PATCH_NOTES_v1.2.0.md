# LUMERIFT v1.2.0 패치 노트

## 목적

기능 추가보다 먼저 전체 UI와 그래픽을 점검하고, 게임이 대시보드처럼 보이던 구조와 서로 충돌하던 색·명암을 수정한다.

## 변경

- 공통 Obsidian·Gold·Teal UI Atlas
- 로비 정보 계층 재설계
- 전투 HUD 압축과 HP 좌표 오류 수정
- 인벤토리 3×4 장비 그리드
- 스테이지 작전 경로와 노드 상태
- 결과 등급·통계·보상 중심 화면
- 플레이어·몬스터 공통 색보정·윤곽 패스
- 배경·초상 v2 기본 경로
- 5개 화면 미리보기와 Visual Audit

## 품질 진실성

현재 단계는 `production-candidate-open-art-pass`다. UI 구조는 개선됐지만 배우·몬스터 아트는 독점 최종 원화가 아니며 `final-approved`로 보고하지 않는다.
