# v1.11.9 자동 전투 진단·고급 설정

## 타겟 진단
- 자동 타겟 점수는 거리·바라보는 방향·등급·공격 예고·잔여 HP·우선순위 보너스로 분해됩니다.
- 전투 HUD의 `LOCK SIGNAL`에서 총점과 대표 선정 이유를 표시합니다.
- 타겟 전환 히스테리시스가 발동하면 `타겟 흔들림 방지 유지`로 표시합니다.

## 행동 이유
자동 전투는 다음과 같은 행동 이유를 실시간으로 표시합니다.
- 공격 거리 접근
- 기본 공격 거리 진입
- 3단 콤보 연결
- HP 조건 충족 스킬 사용
- 스킬 HP 조건 대기
- 공격 예고 자동 회피
- 보스 치명 패턴 회피
- 수동 조작 후 복귀 대기

## 세부 설정
- 자동 스킬 HP 조건: 조건 없음 / HP 85% 이하 / HP 65% 이하 / HP 40% 이하
- 보스 자동 회피: 모든 패턴 / 치명 패턴만 / OFF
- 수동 입력 후 자동 복귀: 즉시 / 0.45초 / 0.9초

## 안전 계약
- 수동 조이스틱·키보드·액션 버튼 입력이 항상 우선합니다.
- 자동 기능은 판정·피해·보상·AI 데이터를 변경하지 않습니다.
