# Equipment and Inventory System v0.4

## 1. 장비 부위

- 무기
- 방어구
- 장신구

장착 슬롯에는 아이템 UID를 저장한다. 아이템 정의 ID와 소유 아이템 UID를 구분한다.

## 2. 등급

- 일반
- 희귀
- 영웅

전설과 신화는 데이터 규격을 확장한 뒤 추가한다.

## 3. 소유 아이템

```text
uid
itemId
level
locked
acquiredAt
```

동일한 장비 정의를 여러 개 획득할 수 있으므로 각 아이템은 독립 UID를 가진다.

## 4. 능력치

장비는 다음 능력치를 제공한다.

- Attack
- Defense
- Max HP

강화 1단계마다 기본 장비 능력치에 12% 누적 배율을 적용한다.

## 5. 전투력

전투력은 공격, 방어, HP와 캐릭터 레벨을 가중 합산한 표시용 수치다.

전투력은 추천 난도 비교용이며 실제 피해 계산식 자체를 대체하지 않는다.

## 6. 강화

- 골드 소모
- 등급과 장비별 기본 비용
- 강화 단계에 따라 비용 증가
- MVP에서는 실패·파괴·하락 없음
- 최대 강화 수치 초과 금지

## 7. 잠금과 판매

- 잠긴 장비는 판매할 수 없다.
- 장착 중인 장비는 판매할 수 없다.
- 일반 일괄 판매는 잠금·장착 장비를 제외한다.

## 8. 드롭

스테이지 JSON의 `dropTable`이 아이템 ID와 확률을 정의한다.

- 한 전투 최대 3개
- 모든 확률이 실패하면 첫 번째 기본 장비 1개 보장
- 결과 화면에서 획득 장비 표시
- 저장 시 독립 UID 생성

## 9. 저장 버전

v0.4부터 `saveVersion: 2`를 사용한다.

v1 데이터에 인벤토리와 장착 슬롯이 없어도 자동으로 빈 구조를 생성하고, 첫 로비 진입 시 스타터 장비를 지급한다.
