# LUMERIFT UI SYSTEM v1.9.0

## 목표

첫 실행 화면부터 전투·인벤토리·운영·계정 화면까지 서로 다른 시기와 질감으로 만들어졌던 UI를 하나의 모바일 판타지 인터페이스로 통일한다.

## 디자인 기준

- 기본 해상도: 540×960, 세로 9:16
- 주색: 심해색 패널, 청록 루멘 발광, 저채도 금속 금색, 은백색 본문
- 정보 우선순위: 장면/캐릭터 → 현재 목표 → 핵심 행동 → 보조 메뉴
- 최소 터치 영역: 44×44 CSS px 상당
- 장식은 판독을 방해하지 않으며 본문·수치·상태가 항상 장식보다 우선한다.
- 모든 런타임 이미지는 PNG 또는 WebP이며 SVG를 사용하지 않는다.

## 공통 런타임 자산

- `ui_luminous_v5`: 패널, 버튼, 탭, 슬롯, HUD, 내비게이션 30프레임
- `ui_icons_v5`: 로그인·재화·메뉴·운영·계정 아이콘 30프레임
- `title_screen_v5.webp`: 모바일 시작 화면 배경
- `UiSkin`: Atlas 로드와 NineSlice 패널 생성
- `UiTheme`: 아이콘, 재화 칩, 메뉴 타일, 구분선 생성
- `UiButton`: 아이콘·부제·정렬을 지원하는 공통 버튼
- `SceneChrome`: 공통 배경, 장면 제목, 부제, 상단 장식

## 화면 적용

### Boot / Title / Login

- 시작 시 로딩 진행률과 룬 애니메이션을 표시한다.
- 로그인 세션이 있어도 타이틀 화면을 먼저 보여 게임 시작 지점을 일관되게 유지한다.
- 게임 시작, 계정 연동, 게스트 로그인, 공지, 설정, 이용약관을 실제 입력 영역에 연결한다.
- 계정 연동 팝업에서 Google·이메일 로그인·회원가입·비밀번호 재설정을 제공한다.

### Lobby

- 상단 재화와 계정 상태, 캐릭터, 오늘의 출석, 이벤트, 일일 퀘스트, 전투 시작을 명확한 순서로 배치한다.
- 스테이지·장비·인벤토리·퀘스트·우편·출석·랭킹·계정 메뉴를 2×4 그리드로 제공한다.
- 하단 내비게이션은 공통 v5 스킨을 사용한다.

### Battle

- 상단 플레이어/보스 HUD와 하단 조작 영역을 분리한다.
- 조이스틱·스킬·회피·기본 공격은 반투명 컨트롤 도크 위에 배치한다.
- 공격 경고 범위와 실제 판정은 v1.8의 `AttackFootprint` 계약을 그대로 유지한다.

### Inventory / Stage / Result / Operations / Account

- 기존 기능 구조는 보존하고 공통 SceneChrome, 버튼, 패널, 탭, 슬롯 텍스처를 적용한다.
- 계정·Cloud Save·복구·랭킹은 기능별 상태색과 명확한 주 행동 버튼을 유지한다.

## 자산과 배포

- v5 UI는 `public/assets/live/v5`에서 실사용한다.
- 교체된 v2 UI는 `art_source/runtime_archive/v1.9.0`에 보존하고 GitHub Pages 배포에서는 제외한다.
- 고해상도 디자인 시안은 문서용 WebP로 축소하고 런타임 번들에는 포함하지 않는다.
- 타이틀·UI Atlas를 포함해도 최초 로딩 입력은 15MB 예산 안에서 관리한다.
