# Boss Threat HUD v1.11.14

보스 텔레그래프를 예고·위험·즉시 회피 세 단계로 구분한다.

- 예고: 패턴 이름과 남은 시간, 이동 경로 확인 안내
- 위험: 치명 단계 진입 전 거리 유지 또는 자동 회피 준비 안내
- 즉시 회피: 강한 점멸과 함께 수동 회피 또는 `AUTO EVADE READY` 상태 표시

자동 전투, 자동 회피, 보스 회피 정책, 현재 전략 프리셋을 함께 읽어 안내 문구를 결정한다. 실제 회피 판정은 기존 `BossDodgeRules`와 `AttackFootprint` 계약을 유지한다.
