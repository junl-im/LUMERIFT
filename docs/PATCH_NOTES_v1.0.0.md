# LUMERIFT v1.0.0 패치 노트

## 핵심

로비와 전투에서 사용하던 구조 검증용 절차형 자산을 실제 공개 라이선스 게임 아트로 교체했다.

## 비주얼

- 실제 판타지 로비·전투 배경
- 실제 영웅·보스 초상
- 실제 플레이어 전투 시트
- 오크·거미·웨어베어·트롤 기반 몬스터 8종
- 금속·유리 질감 UI와 NineSlice 18종

## 기술

- 기존 상태·방향·몬스터 ID 키 계약 유지
- 종별 애니메이션 연결
- Lazy Loading·씬 종료 해제 유지
- 라이브 아트·라이선스 자동 검사 추가

## 품질 고지

`production-candidate-open-art-pass` 단계다. 실제 게임에 사용 가능한 공개 원본이지만 LUMERIFT 독점 최종 원화는 아니다.
