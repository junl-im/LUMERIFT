# LUMERIFT v1.11.23 Patch Notes

## 독립 장비 외형 레이어

- 갑주·망토·룬을 본체 스프라이트와 분리된 프로그램 런타임 레이어로 추가했다.
- 전투 방향, 공격·스킬 진행률, 회피, 오버드라이브에 따라 망토 흔들림·갑주 투명도·룬 발광이 개별 반응한다.
- 캐릭터 아틀리에의 BEFORE/AFTER 비교에도 같은 레이어를 사용한다.
- 신규 이미지 자산은 추가하지 않았다.

## 외형 프리셋 보관소

- 최근 수정순·즐겨찾기 우선·이름순 정렬을 지원한다.
- 프리셋 이름, 코스튬 세트, 방향, 포즈를 검색한다.
- 외형 슬롯 3개를 고정할 수 있다.
- 고정 슬롯은 수동 덮어쓰기와 JSON 가져오기 교체로부터 보호된다.
- Archive 스키마를 v2로 확장했으며 v1 JSON 가져오기를 유지한다.

## 실기기 캡처 승인 흐름

- Android Chrome과 iOS Safari용 캡처 템플릿을 제공한다.
- `approved=true`, 검토자, 촬영 시각, CSS viewport, DPR, 캡처 파일 2개 이상, 허용 범위 보정값을 모두 검증한다.
- 조건을 충족한 승인 JSON을 가져온 플랫폼만 `capture-verified`로 적용한다.
- 프로젝트 자체에서 물리 단말 캡처를 완료한 것으로 기록하지 않는다.

## 선택형 Cloud Save 설계

- `manual-opt-in` 외형 프리셋 봉투와 UID 가드를 추가했다.
- 문서 경로는 `users/{uid}/settings/characterAppearance`다.
- Firestore 실제 읽기·쓰기는 아직 연결하지 않았다.
