# v1.11.8 자동 기능·실기기 전투 보정

## 자동 타겟 우선순위
- 균형
- 가까운 적
- 보스·엘리트
- 낮은 HP
- 공격 예고

## 자동 전투 세부 설정
- 자동 스킬 ON/OFF
- 자동 회피 ON/OFF
- 보스전 전체 자동
- 보스전 타겟만
- 보스전 자동 금지

## 실기기 반응 프리셋
- 즉응형: 타겟 전환과 회피 판단을 빠르게 수행
- 균형형: 기본 권장값
- 안정형: 타겟 전환을 줄이고 행동 간격을 넓힘

## 안전 계약
- 수동 입력 우선
- 튜토리얼 자동 전투 금지
- 자동 타겟 OFF 시 자동 전투도 OFF
- 피해 공식·공격 판정·AI·보상은 변경하지 않음
