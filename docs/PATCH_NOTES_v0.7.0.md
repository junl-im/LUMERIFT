# LUMERIFT v0.7.0 패치 노트

## 전투 조작

- 좌측 하단에 Dead Zone과 최대 드래그 반경을 적용한 가상 조이스틱을 추가했다.
- 공격·스킬 2종·회피를 원형 모바일 버튼으로 재구성했다.
- 스킬 및 회피의 남은 시간을 원형 오버레이와 숫자로 표시한다.
- 키보드와 기존 전투 지역 드래그 이동은 그대로 유지한다.

## 전투 연출

- Slash, Nova, Hit, Explosion, Dodge 애니메이션을 포함한 WebP VFX Atlas를 추가했다.
- 짧은 수명의 전투 이펙트는 Object Pool로 재사용한다.
- 보스 등장 시 줌·진동·폭발 연출을 적용했다.
- 보스 HP 65%와 30%에서 2·3페이즈로 전환하며 속도, 공격력과 패턴 시작점이 강화된다.
- 그래픽 품질에 따라 파티클 생성 빈도와 배경 애니메이션 속도를 자동 축소한다.

## 캐릭터·장비·UI

- 장비 9종 WebP 아이콘 Atlas를 추가했다.
- 인벤토리 목록과 상세 정보에 장비 아이콘을 연결했다.
- 로비 캐릭터를 AnimatedSprite로 표시하고 장착 무기를 별도 레이어로 표현한다.
- 전투 플레이어에도 장착 무기 아이콘 레이어를 연결했다.
- 씬 전환 페이드와 전환 중 입력 차단을 추가했다.
- 전투 리소스 로딩 진행률과 텍스처 GPU 준비 단계를 추가했다.

## 오디오

- 스킬과 회피 OGG 효과음을 추가했다.
- 기존 공격·피격·BGM 캐시와 함께 전투 종료 시 해제한다.

## 주의사항

현재 시각·음향 리소스는 최종 상용 에셋이 아니라 제작 규격과 런타임 구조 검증용이다. npm Registry 연결 제한으로 실제 의존성 설치, Vitest 전체 실행, Vite 프로덕션 빌드와 브라우저 실기동은 사용자 환경에서 최종 확인한다.
