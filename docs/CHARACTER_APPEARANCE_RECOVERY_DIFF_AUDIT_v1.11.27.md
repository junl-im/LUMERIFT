# 캐릭터 외형 복구 차이·감사 기록 v1.11.27

## 목적

외형 복구 지점을 단순히 이름과 생성 시각으로만 선택하지 않고, 두 Archive의 실제 캐릭터 외형과 변경 필드를 복원 전에 확인한다. Cloud 병합·복구·Undo 관련 작업은 사용자 UID별 감사 기록으로 남겨 인수인계와 문제 재현에 사용할 수 있다.

## 복구 지점 비교

- 복구 센터에서 현재 선택 지점과 다음 검색 결과 지점을 비교한다.
- POINT A와 POINT B는 실제 플레이어 Atlas, 무기 공격 Atlas, 갑주·망토·룬 장비 레이어를 사용한다.
- 슬롯 1·2·3을 순환하며 저장 외형, 고정 상태, 염색, 코스튬, 방향, 포즈를 확인한다.
- 슬롯 순서, 고정 슬롯, 최근 프리셋의 추가·삭제·변경도 Archive 차이에 포함한다.
- 비교 화면은 데이터를 변경하지 않으며 명시적인 복구 버튼도 제공하지 않는다.

## 차이 자료 내보내기

`lumerift-character-appearance-recovery-comparison-v1` JSON에는 다음 항목이 포함된다.

- 비교 대상 복구 지점 ID·이름·생성 시각·사유
- `lumerift-character-appearance-diff-v1` 상세 차이
- 두 복구 지점과 연결된 계정 감사 기록
- 좌우 Archive revision

## 감사 기록

- 스키마: `lumerift-character-appearance-audit-archive-v1`
- 저장 범위: 사용자 UID별 분리
- 최대 기록: UID당 최근 100건
- 기록 대상: 복구 생성·이름 변경·고정·삭제·가져오기·복원, Cloud 동기화 검사, 업로드·대기, 충돌 선택 병합, 병합 Undo, 복구 차이 내보내기
- 다른 UID의 기록은 목록과 내보내기에 포함하지 않는다.
- 감사 기록은 진단 자료이며 Player Save v4 또는 Firestore 게임 진행 데이터에 포함하지 않는다.

## 안전 규칙

- 비교·내보내기는 로컬 외형과 Cloud 문서를 변경하지 않는다.
- 복구는 적용 전에 현재 외형을 다시 백업한다.
- 고정 슬롯과 계정 UID 보호 규칙을 계속 유지한다.
- 감사 기록에는 비밀번호·인증 토큰·Firebase 자격 증명을 저장하지 않는다.
