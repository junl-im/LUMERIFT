# 모바일 제작용 원본 아트 정책

## 목적

전체 통합본에는 재가공 가능한 원본을 보존하되, 모바일 웹게임에 불필요한 초고해상도와 비압축 PNG로 저장소 용량을 키우지 않는다.

## 원칙

1. LUMERIFT 소유 원본은 화면 용도별 최대 해상도를 적용한다.
2. 투명도가 필요한 원본은 최적화된 PNG로 보관한다.
3. 런타임에서는 WebP와 Texture Atlas를 사용한다.
4. 제3자 원본은 라이선스·가공 재현을 위해 원본 상태로 보관할 수 있다.
5. `art_source`는 GitHub Pages 배포 대상이 아니다.
6. `npm run validate:sourceart`가 해상도와 총 용량 예산을 검사한다.

## 용량 예산

- 전체 `art_source`: 60MB 이상, 120MB 이하
- LUMERIFT 소유 제작 원본: 40MB 이상, 90MB 이하
- 개별 LUMERIFT 소유 PNG: 5MB 이하

용량은 십진 단위 MB로 기록한다.
