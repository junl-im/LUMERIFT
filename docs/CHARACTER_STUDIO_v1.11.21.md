# Character Studio v1.11.21

## 범위

- 캐릭터 스튜디오에서 북·북동·동·남동·남·남서·서·북서 8방향을 수동 회전한다.
- 현재 장비와 선택한 교체 후보를 동일 포즈·방향·염색 상태로 좌우 동시 렌더링한다.
- 비교 슬롯은 무기·방어구·장신구를 순환하며 실제 장착 정보와 Player Save v4는 변경하지 않는다.
- 정찰대 강철·감시자 균열·전령 계승 코스튬 세트와 갑주·망토·룬 3개 세부 염색 채널을 제공한다.
- 기존 3개 로컬 외형 슬롯을 확장하고 최근 프리셋 최대 5개를 빠르게 적용한다.

## 저장 계약

외형 상태는 `CharacterWardrobeController`가 로컬 표시 설정으로 저장한다. v1.11.20의 염색·포즈 슬롯은 방향·코스튬·채널 기본값을 채워 자동 마이그레이션한다. 장비 능력치, 성장, 보상, Cloud Save 스키마는 변경하지 않는다.

## 비교 계약

교체 후 미리보기는 `equipmentOverrides`를 사용해 계산한 임시 `CharacterEquipmentAppearance`다. 실제 인벤토리 UID나 장착 슬롯을 수정하지 않으며 화면을 벗어나면 비교 후보만 로컬 UI 상태로 남는다.
