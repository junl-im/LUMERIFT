# LUMERIFT v1.8.0 보스 전투·판정 동기화

## 목적

기존 부채꼴 공격은 실제 충돌은 각도 기반인데 화면 경고는 타원으로 표시되어 경계가 달랐다. v1.8.0은 `AttackFootprint`를 경고 표시, 실제 충돌, 타격 잔상에 공통 사용한다.

## 구현

- 원형: 중심·반경과 대상 반경을 동일하게 계산
- 부채꼴: 방향 벡터·사거리·반각을 동일하게 사용
- 경고와 타격 폴리곤은 같은 부채꼴 샘플링 함수 사용
- 보스 3페이즈마다 타이틀, 색상, 오라 링, 줌, 흔들림, 경고 강도 변경
- 연출 중 전투 로직을 일시 정지하고 보스 위치에 카메라 집중
- 실제 적중 시에만 Hit Stop·Shake·Pulse Zoom 실행

## 제한

보스 전신 외형은 v1.7 공개 원본 통일 아트를 유지한다. 이번 버전은 연출과 판정의 일치 개선이며 독점 최종 원화 교체가 아니다.
