# Premium UI Icons v1.11.32

512×512 투명 WebP에 16개 프리미엄 아이콘을 제공한다.

- 스킬: 기본 공격, 균열 충돌, 심연 폭발
- 장비 등급: Common, Rare, Epic, Legendary/Heroic
- 보스 패턴: Slash, Charge, Burst, Summon, Core Break
- 장비·상태: Weapon, Armor, Accessory, Boss Phase

BattleScene과 InventoryScene이 v16을 우선 사용하고, 로딩 실패 시 Premium HUD v15와 기존 UI로 폴백한다. 아이콘은 표현 계층이며 게임 데이터는 변경하지 않는다.
