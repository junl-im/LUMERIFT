# 전투 HUD 접근성 v1.10.1

## 모드

- 표준 색상: 기존 LUMERIFT 색상 체계
- 색상 보조: 플레이어 HP는 청록, 위험 HP는 황색, 보스 HP는 보라로 분리
- 고대비: 밝은 청록·노랑·분홍과 검정/흰색 윤곽을 함께 사용

색상만으로 상태를 전달하지 않는다.

- `♥`: 플레이어 HP 정상
- `▲`: 플레이어 HP 위험
- `◆`: 보스 HP

## 추가 설정

- 큰 HUD: 전투 HP·보스명·조작 안내 글자를 확대하고 DOM 입력 버튼 최소 높이를 52px로 늘린다.
- 연출 완화: 전투 카메라 흔들림을 기본값의 28%로 제한한다.

설정은 `localStorage`의 `lumerift.accessibility.v1`에 저장되며 Firebase 저장 데이터에는 포함하지 않는다. 계정 진행과 접근성 개인 설정을 분리하기 위한 결정이다.
