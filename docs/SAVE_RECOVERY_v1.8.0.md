# LUMERIFT v1.8.0 Cloud Save 복구 지점

## 저장 위치

복구 지점은 브라우저 `localStorage`의 `lumerift.cloud.recovery.v1.{uid}`에 UID별 최대 5개 저장한다. Firestore에는 업로드하지 않아 무료 읽기·쓰기 사용량을 늘리지 않는다.

## 자동 생성 시점

- 클라우드 다운로드 전
- 수동 클라우드 업로드 전
- 클라우드 최신본 자동 병합 전
- 로그아웃 전

계정 화면에서 현재 상태를 수동 백업할 수도 있다. 복원 시 새 `updatedAt`을 발급하고 로컬 저장 후 Cloud Save 동기화를 시도한다.

## 주의

브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기에서는 로컬 복구 지점이 유지되지 않는다. 서버 스냅샷 기능은 후속 버전에서 별도 설계한다.
