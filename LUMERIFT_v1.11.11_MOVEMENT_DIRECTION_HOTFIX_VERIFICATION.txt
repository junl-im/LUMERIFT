LUMERIFT v1.11.11 Movement Direction Hotfix Verification
Date: 2026-07-30

ROOT CAUSE
- VirtualJoystick already returned screen coordinates correctly.
- JoystickCalibrationController defaulted to reverse.
- BattleScene applied that default to every virtual joystick input.
- Therefore X/Y position, facing and 8-direction animation all moved opposite to the finger direction.

FIX
- Default calibration changed from reverse to screen.
- Calibration order changed to screen -> invert-x -> invert-y -> reverse.
- Storage key changed from lumerift.joystickCalibration.v1 to v2 so the retired reverse default is not reused.
- Explicit correction modes remain available in Settings.
- Added JoystickCalibrationController.test.ts.

VERIFIED
- Right input => {x: 1, y: 0}
- Left input => {x: -1, y: 0}
- Up input => {x: 0, y: -1}
- Down input => {x: 0, y: 1}
- Explicit reverse still maps {x: 1, y: -1} to {x: -1, y: 1}.
