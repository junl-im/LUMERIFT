# LUMERIFT: 균열의 계승자 v1.11.5

모바일 웹 우선 9:16 액션 RPG. Vite + TypeScript + PixiJS 8 + Firebase 기반이다.

## v1.11.5 핵심
- 웹툰형 감성의 클린 UI 리디자인: 패널 하이라이트, 스티커형 포인트, 버튼 광택, 액션 태그 강화
- 전투 HUD 대정리: HERO CUT 플레이어 카드, HYPE METER, ATTACK VECTOR 텔레메트리, 더 읽기 쉬운 전장 정보
- 캐릭터 방향 시각 검수: 이동/공격 방향을 HUD와 조이스틱 가이드에서 더 선명하게 노출
- 타격감 강화: CRIT/BURN/HIT 플로팅 텍스트, CHAIN/CRITICAL 배너, 공격 방향 표시가 포함된 VFX 보강
- 기존 입력 보정·전투 접근성·다층 음향·선택형 플레이어 아트 계약 유지

## 실행·검증

```bash
npm install
npm run verify
npm run dev
```
