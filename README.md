# LUMERIFT: 균열의 계승자 v1.11.4

모바일 웹 우선 9:16 액션 RPG. Vite + TypeScript + PixiJS 8 + Firebase 기반이다.

## v1.11.4 핵심
- 입력 방향 보정: 가상 조이스틱 기본값을 반전 보정으로 조정하고 설정에서 순환 교정 가능
- 캐릭터 업그레이드: 그림자·발밑 포커스 링·실루엣 glow·기본 원화 스케일 상향
- UI 개선: 더 밝은 패널, 대비 강화, 설정 화면 정리
- 기존 QA 분석·선택형 도색 후보·전투 진동/화면 낭독·다층 음향 유지

## 실행·검증

```bash
npm install
npm run verify
npm run dev
```
